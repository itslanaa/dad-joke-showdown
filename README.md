## The joke

> My vacuum cleaner quit, so I told it to suck it up. Now it's working again and I'm the one who feels drained.

A double pun, delivered straight-faced in a single sentence: "suck it up" is both the vacuum's job and the advice given to it, and the punchline flips the drain onto the speaker.

## How it works

`main.ts` writes the joke (110 characters, within the 1–200 character limit) to `/output/entry.txt`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/dad-out node main.ts
cat /tmp/dad-out/entry.txt
```
